# UXLens Browser Extension

This Manifest V3 extension collects privacy-safe UX evidence from configured websites and sends it to the existing UXLens backend.

## Local setup

1. Start the UXLens backend on `http://localhost:4000`.
2. Open Chrome or Chromium extensions and enable developer mode.
3. Load the repository's `extension` directory as an unpacked extension.
4. Open the extension options page.
5. Enter the backend URL and a UXLens project ID.
6. Enter the project ingestion key generated by the backend owner.
7. Save the configuration after project validation succeeds.
8. Open the Tracker Test Website in a normal browser tab.

The extension sends `page_view`, `click`, `hover`, and page-load `navigation` events to `POST /api/events`. It does not reuse `tracker.js`, inspect form values, read browser storage, capture page HTML, or perform friction analysis.

Collection remains disabled until a valid project ID is saved.
